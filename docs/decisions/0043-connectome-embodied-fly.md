# ADR 0043: Real-Time Embodied *Drosophila* — Brain ↔ Body Level 1 (F8)

- Status: Accepted
- Date: 2026-11-23
- Related: ADR 0035 (species-pack), ADR 0036 (LIF engine), ADR 0037 (3D brain viz), ADR 0030 (MuJoCo CPU), `docs/plans/connectome_plan.md`

## Context

Phase F8 Level 1 (`docs/plans/connectome_plan.md` §4 F8) couples the spiking adult *Drosophila*
connectome brain (138,639 neurons / 15,091,983 edges in FlyWire v783) bidirectionally every 1 ms
to a 6-legged MuJoCo 3 physics body in an interactive arena, displaying the 3D arena and the 3D
glowing brain side by side in the browser.

Mandatory engineering and scientific integrity constraints:

1. **Honest Level 1 boundary:** Leg oscillation rhythms and the stumble reflex are **hand-crafted**
   (a Level 1 tripod CPG inspired by NeuroMechFly v2, Wang-Chen et al. 2024), NOT generated by a
   biological VNC connectome (which is deferred to Level 2 with BANC/MaleCNS). Every UI banner,
   preset description, CLI output, and metric explicitly states this distinction.
2. **Body asset boundary (user-approved):** Only the Apache-2.0 NeuroMechFly v2 body asset pack
   (51 files, 3.50 MiB: `LICENSE`, 45 simplified CT-scanned STL meshes, rigging/pose YAML, MJCF)
   is downloaded to `.alife/datasets/neuromechfly_v2/` outside Git with SHA-256 `manifest.json`.
   No FlyGym Python code is installed. A built-in procedural capsule-contact 6-legged fly MJCF runs
   identically in offline CPU-only CI and provides fast deterministic floor contacts.
3. **Real-time closed-loop budget (`>= 1.0x` real time):** Brain runs on GPU via `CupyLIFRunner`
   CUDA graphs (10 × 0.1 ms substeps per 1 ms tick) while MuJoCo runs on CPU float64 (2 × 0.5 ms
   substeps per 1 ms tick). Host↔device transfer per tick is restricted to `< 4 KB` sensory updates
   and `< 1 KB` descending/motor command spike reads (`upload_stim_subset` / `read_spike_subset`).
4. **Exact deterministic checkpoint & negative controls:** Both the spiking LIF brain state and
   MuJoCo `qpos`/`qvel`/`ctrl` + CPG phase + arena state are checkpointed together for exact
   replay/fork. Silencing motor neurons (`MN9`) or shuffling connectome wiring (`shuffled_control`)
   must demonstrably break the corresponding behaviors.

## Decision

### 1. FlyWire v783 verified anatomical command decoder (`src/alife_lab/connectome/embodied.py`)

Probing the real 138,639-neuron FlyWire v783 Shiu et al. (2024) LIF model established exact
zero-crosstalk specificity for our F8 behavioral circuits:

- **Sugar feeding (`sugar_grn -> MN9 / CB0701`):** `sugar_grn` (190 Hz) drives `MN9` (`CB0701`,
  2 cells) strongly while leaving `DNg84` silent (`0` spikes); co-stimulating `bitter_grn` suppresses
  `MN9` via biological FlyWire inhibitory circuits.
- **Antennal grooming (`antennal_grooming_mechanosensory -> DNg84`):** Probing all 1,299 descending
  neurons under antennal mechanosensory stimulation revealed `DNg84` as the #1 selective grooming
  descending neuron (zero response to sugar, odor, or walking drive; whereas `DNg35` responds to
  both odor and touch and was excluded from the grooming decoder to eliminate crosstalk).
- **Locomotion & steering (`DNp09`, `DNa01`/`DNa02`, `MDN`):** Decoded via 30 ms exponential
  low-pass filters into `[0, 1]` command meters driving the Level 1 6-leg tripod CPG (`fly_body.py`).
- **Silenced output masking:** Because `LIFState.silenced` blocks outgoing synaptic transmission
  inside the brain, decoded muscle/descending commands are also masked by `silenced == 0` so
  silencing `mn9_proboscis_extension` cleanly blocks proboscis extension.

### 2. Platform integration (`fly_embodied` substrate & 2-pane Browser UI)

- Registered `fly_embodied` (`FlyEmbodiedAdapter`, `mode="exploratory"` only, `backends=("numpy",
  "cupy")`), streaming a unified `fly_embodied_v1` binary packet (`[geom transforms f32][fired cell
  indices i32]`).
- Built `frontend/src/components/EmbodiedFlyView.tsx`: side-by-side 3D MuJoCo Arena + synced 3D
  glowing `Brain3D`, honest Level 1 banner with live real-time factor & latency breakdown, 5 live
  command meters, body-part ↔ brain circuit links, and live intervention buttons (`place_food`,
  `poke_antenna`, `silence`, `clear_food`).
- Added CLI `alife connectome embody {flywire_783,synthetic_fly_embodied}`, 4 catalog presets,
  offline 24-neuron `synthetic_fly_embodied` test circuit, unit tests (`test_connectome_f8.py`),
  and Playwright E2E test (`e2e/connectome.spec.ts`).

## Consequences

- On the full **138,639-neuron, 15,091,983-edge FlyWire v783** brain + CPU MuJoCo 3.17.0 6-legged
  fly (RTX 5070 + Ultra 7 270K Plus), **all 6/6 F8 acceptance gates pass** (`sugar_triggers_feeding`,
  `bitter_suppresses_feeding`, `antenna_poke_triggers_grooming`, `mn9_silencing_breaks_feeding`,
  `shuffled_wiring_breaks_feeding`, `shuffled_wiring_breaks_grooming`) at **1.80x – 2.70x real time**
  (`brain = 0.012–0.043 ms`, `body = 0.093–0.130 ms`, `transfer = 0.265–0.394 ms` per 1 ms tick).
- CPU-only CI remains green without MuJoCo or GPU hardware (`@needs_mujoco` guards physics tests).
